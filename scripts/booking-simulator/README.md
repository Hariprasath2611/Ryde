# Booking Simulator

This tool will simulate end-to-end trip lifecycles in local and staging environments without requiring real mobile devices or physical vehicles.

## Capabilities (Planned)

- Emulate customer booking creation and pricing quotation.
- Dispatch simulated driver location updates along generated polylines.
- Auto-simulate OTP generation, vehicle handover checklist, and trip completion.
- Stress-test concurrent driver dispatch algorithms and PostGIS proximity queries.
